## ⌨️ Comandos y pasos importantes

- `pwd` — comprueba el directorio actual antes de ejecutar comandos para asegurar que estás dentro de `01_Practicas`.
- `git clone <url_repo> <nombre_carpeta>` — clona un repositorio descargando su historial completo `.git` y asignando el nombre de carpeta adecuado en la bóveda.
- `git status` — consulta el estado del árbol de trabajo o verifica si la carpeta actual es un repositorio Git válido.
- `git add .` — añade los archivos creados o modificados al área de preparación (*staging*).
- `git commit -m "<mensaje>"` — guarda los cambios en el historial local con un mensaje explicativo.
- `git push` — sube las confirmaciones guardadas desde el repositorio local al repositorio remoto en GitHub.
- `git remote -v` — comprueba las URL de los repositorios remotos para verificar que apuntan a tu usuario.

## 🤔 Respuestas a las preguntas

1. **¿Qué hace *Use this template* y sobre qué repositorio trabajas?**  
   Crea un repositorio nuevo e independiente en tu cuenta personal de GitHub con su propio historial. A partir de ese momento trabajas sobre **tu repositorio**, pudiendo hacer cambios y `git push` sin requerir permisos en el repositorio del profesor.
2. **¿Por qué el clonado por HTTPS no pidió contraseña y cuándo sí la pediría?**  
   No pide contraseña al clonar porque el repositorio es **público** y la lectura está abierta a cualquiera. Pediría identificación (token o credenciales) únicamente al intentar subir cambios con `git push`.
3. **¿Qué diferencia hay entre la carpeta del ZIP y la clonada?**  
   La carpeta del ZIP solo contiene los archivos del proyecto, pero carece de la carpeta oculta `.git` donde se almacena el historial. Sin ella no puedes consultar el estado o historial (`git status`, `git log`), recuperar archivos eliminados (`git restore`), ni subir cambios a GitHub (`git push`).
4. **¿Qué debes hacer para consultar en casa una nota creada en la terminal del aula?**  
   Guardar la anotación en un archivo propio (como `MIS_NOTAS.md` o `MIS_DATOS.md`) dentro de la carpeta del repositorio y ejecutar `git push` para sincronizar los cambios con tu repositorio remoto en GitHub.
