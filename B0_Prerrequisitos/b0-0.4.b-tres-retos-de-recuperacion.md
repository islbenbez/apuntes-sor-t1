## 🎯 Qué se pedía

Aprender a recuperar ficheros borrados localmente mediante `git restore .` sin necesidad de Internet, reconstruir un repositorio completo mediante `git clone` cuando se borra la carpeta oculta `.git`, y comprobar de forma práctica que cualquier archivo o nota propia a la que no se le haga `git push` se pierde de manera irreversible al borrar la carpeta.

## ⌨️ Comandos y pasos importantes

- `git restore .` — devuelve todos los archivos borrados o modificados al estado del último commit (el punto indica "todo desde la ubicación actual hacia abajo").
- `git status` — comprueba qué ficheros faltan (marcados con `D` de *deleted*) o advierte si no existe un repositorio Git en la carpeta actual.
- `git clone <url_repo> <nombre_carpeta>` — vuelve a descargar un repositorio completo desde GitHub con su historial `.git`.
- `git log --oneline` — comprueba el historial resumido de commits para verificar la recuperación de los cambios subidos.

## 🚩 Qué me ha fallado y cómo lo he resuelto

- **Mensaje de error LITERAL:**  
  `fatal: you must specify path(s) to restore`.
- **Causa y resolución:**  
  Ocurrió al ejecutar el comando `git restore` habiendo olvidado escribir el punto final. Se resuelve especificando la ruta o añadiendo el punto (`git restore .`), el cual indica a Git que aplique la restauración a todos los archivos desde la carpeta actual hacia abajo.

## 🤔 Respuestas a las preguntas

1. **¿Por qué el Reto 1 se arregla sin Internet y el Reto 2 no?**  
   El Reto 1 se soluciona localmente porque la máquina del tiempo de Git (la carpeta oculta `.git`) sigue estando dentro de tu ordenador. En el Reto 2, al eliminar la carpeta completa del repositorio se borra también `.git`, de modo que no queda historial local y es imprescindible conectarse a Internet para clonar todo de nuevo desde GitHub.
2. **En el Reto 3 el repositorio era tuyo y aun así perdiste las notas. ¿Qué faltó?**  
   Faltó realizar `git push`. Al no haber subido la nota al servidor remoto de GitHub, el archivo solo existía en el almacenamiento local que fue eliminado.
3. **Un compañero anota cosas en su carpeta de prácticas del aula y no entiende por qué en casa no le salen. Explícaselo en dos frases.**  
   Las notas creadas en el equipo del aula solo existen en el disco duro de esa máquina hasta que ejecutas `git push`. Si te vas a casa sin subir los cambios a GitHub, al abrir tu repositorio desde otro ordenador esa información nunca habrá llegado al servidor remoto.
